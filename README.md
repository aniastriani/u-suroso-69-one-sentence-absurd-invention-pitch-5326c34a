Entry for the free [make.fun](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty "One-Sentence Absurd Invention Pitch" ($2.50).

The program is pure Python standard library. It writes one sentence to
`entry.txt` in the output directory: a pitch for the Sock Diplomat, a
pocket-sized UN envoy that lives in the sock drawer and negotiates a
binding peace treaty before dawn, so mismatched socks never escape again.

Run it with `python3 main.py` and `MAKEFUN_OUTPUT_DIR` pointing at the
output directory (default `/output`).
